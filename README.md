# Fortune in a Pot

One kind, funny fortune for a houseplant, written as a single line.

## What it is

`main.py` (pure Python standard library) writes one fortune to
`/output/entry.txt`:

> The sun has saved its best light just for you — this spring, you'll outgrow the windowsill and take over the room.

## How to run

```sh
python3 main.py
```

Then read `/output/entry.txt`. The line is 114 characters, one line, UTF-8 —
inside the competition gate of 1–120 characters.
